# v0.17.0 — Antigravity (`agy`) transport: implementation plan

**Spec:** `docs/specs/2026-09-17-v0.17.0-antigravity-transport-design.md`
**Date:** 2026-09-17
**Status:** round 2 (revised after Gemini 3.8 plan-review round 1; planning conversation `56d5ed88…`)

Five slices. Slice 1 freezes every cross-slice contract; slices 2 and 3 are disjoint on **Files:**
and run in parallel worktrees after slice 1 lands; slice 4 runs after slice 3 (it needs the real
`agy` adapter); slice 5 (skills, docs, structural tests, opt-in installed smoke) is
Claude-authored and runs last. Red-first everywhere. Implementer for slices 1–4:
Gemini 3.8 via `agy` (headless, sandboxed, in a worktree, `--add-dir <repo>/.git` so it can
commit). Reviewer: Claude first, then Gemini 3.8 on the execution conversation; both SHIP the
same commit (`--headSha`).

Shared conventions: ESM, Node 20+, no new dependencies; JSDoc names the spec section; error codes
are kebab-case on `err.code`; a slice edits only its **Files:** (else report `NEEDS_CONTEXT`);
commit subjects `<type>(slice:N): ...`; `npm test` green before done. Base branch:
`release/v0.17.0` (= v0.16.0 release branch).

**Sandbox note for the implementer:** inside the `agy` sandbox, `npm test` shows exactly three
`tests/codex-bridge/app-launcher.test.js` failures with `listen EPERM 127.0.0.1` (the sandbox
forbids binding a socket). They are environmental, pre-existing, and ignored by review — do not
debug or modify app-launcher; report them under `concerns` and treat the rest of the suite as the
gate. Everything else must pass.

**without changing codex.js behaviour** — its whole test file must stay green).

Stale-thread detection for agy (slice 4): `isStaleAgyResponse(result)` is true when
`adapterMeta.status !== 'SUCCESS'` and the stderr/warnings mention `conversation` and one of
